# Blog Michi Lovers

Blog Michi Lovers es un proyecto en desarrollo dedicado a los gatos. El repositorio contiene páginas HTML iniciales y archivos JavaScript de prueba.

## Contenido

- `adopcion.html`: página inicial sobre la adopción de gatos.
- `articulo.html`: plantilla inicial para un artículo.
- `Michi-lovers.js`: archivo JavaScript de prueba.

## Cómo verlo

No se requiere instalar dependencias. Abre `adopcion.html` en un navegador para ver la página inicial. También puedes abrir `articulo.html`; actualmente es una plantilla vacía.

## Ejecutar el archivo JavaScript

Si tienes [Node.js](https://nodejs.org/) instalado, puedes ejecutar el archivo de prueba desde la carpeta del proyecto:

```bash
node Michi-lovers.js
```

Este comando ejecuta JavaScript en la terminal; no inicia un servidor web.
